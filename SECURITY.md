# Security policy

## Supported versions

| Version | Supported |
| --- | --- |
| 1.x (in development) | Yes |
| 0.9 | Critical fixes only |
| Older | No |

## Reporting a vulnerability

Please do not report security issues in public issues or pull requests.

Report them privately through [GitHub's private vulnerability reporting](https://github.com/sigmafieldlabs/finalytics/security/advisories/new),
or by email to nnamdi@sigmafieldlabs.com. Include a description of the issue, the affected
versions, and steps to reproduce it.

You will receive an acknowledgement within three working days. We will keep you informed while
we investigate, and credit you in the release notes unless you prefer otherwise.
